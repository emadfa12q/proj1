# نگاشت قابلیت‌های نسخه ویندوز به اندروید

| نسخه ویندوز Python/PySide | نسخه اندروید |
|---|---|
| PySide6 GUI | Native Android Java UI |
| SQLite local DB | SQLiteOpenHelper local DB |
| win32gui foreground window | UsageStatsManager foreground app |
| ImageGrab screenshots | محدود توسط اندروید؛ مقدار خالی ثبت می‌شود |
| System tray | Foreground service notification |
| Startup folder / VBS | BootReceiver + foreground service |
| Jalali calendar/report | JalaliUtils داخلی بدون وابستگی خارجی |
| PDF با reportlab | Android PdfDocument |
| تم dark/light | ذخیره در settings table |
| Tags | انتخاب ردیف‌ها و update در SQLite |
| Timesheet ماهانه/بازه‌ای | صفحه Timesheet/Reports |
